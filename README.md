## Key Learning Concepts

1. **HTML Essentials**:
   - Semantic tags, document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
   - Lists: Unordered (`<ul>`), Ordered (`<ol>`), and Description (`<dl>`).
   - Tables with multi-cell spans (`colspan`, `rowspan`).
   - Media embedding: Images (`<img>`) and external video players (`<iframe>`).

2. **CSS Foundations**:
   - Ways to apply styles: Inline styles, Internal `<style>` tags, and External `.css` stylesheets.
   - Selectors: Tag/Element selectors, Class selectors (`.`), and ID selectors (`#`).
   - CSS Box Model: `margin`, `border`, `padding`, `width`, and `height`.
   - Typography and layout formatting.
